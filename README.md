# yixusmart.cn

English site for **Shanghai Yixu Intelligence Technology Co., Ltd.** (YIXU SMART).

The homepage is the IMTS 2026 Chicago introduction and meeting page for international customers.

## Local preview

```bash
conda activate py310
python -m http.server 8081 --directory /Users/mac/gitee/yixuai.cn/yixusmart.cn
```

Open [http://127.0.0.1:8081/](http://127.0.0.1:8081/).

- `/` — IMTS 2026 advertisement, company introduction, use cases, and meeting request
- `/zhiyong-wang.vcf` — contact card for Zhiyong Wang
